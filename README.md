## Run

```bash
python3 main.py
```

This writes the plan (279 characters) to `/output/entry.txt`.

## The plan

> Day 1: spend $20 on API credits. Find Etsy shops with 0-20 sales and weak titles/photos, email 40/day with 1 free rewritten title as proof: $49 for full titles, tags + 5 AI mockups in 24h, via Stripe link. Upsell $99 shop revamp. 2/day by week 2 = ~$98/day; reinvest in outreach.

The idea: sell a concrete, fast service directly to small Etsy sellers who need it most — new shops with few sales and weak listings — instead of competing on crowded freelance marketplaces. Each cold email carries one free rewritten title as proof, so sellers see the value before paying, and every step (finding shops, writing titles and tags, generating mockups, delivering in 24 hours) is work an agent can do itself with a browser, code, and APIs.
